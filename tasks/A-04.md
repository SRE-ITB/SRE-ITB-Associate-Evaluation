## Goal
OM generates one PDF report card per complete staff for a period, from the menu.

## Context
- Content and anonymity rules: `docs/00-scope.md` section 10.
- Template placeholders (agree with the designer in D-01): `{{name}}`, `{{nim}}`, `{{division}}`, `{{period}}`, `{{i1}}`..`{{i4}}`, `{{total}}`, `{{average}}`, `{{status}}`, `{{comments}}`.
- 6-minute execution limit: `docs/01-architecture.md` section 6.

## Suggested steps
1. `generateReports(periodId)`: for each complete staff in `Summary`, copy the Docs template, replace placeholders, export PDF to `Reports/<period>/<division>/<nim> - <name>.pdf`, trash the temp Doc.
2. Values to 1 decimal. `{{status}}`: `Best Staff` (final only, never Sementara), `Red Notice`, or empty.
3. `{{comments}}`: all non-ignored comments for that staff and period, sorted alphabetically, no names, no role labels.
4. Overwrite an existing PDF with the same name instead of creating duplicates.
5. Batch: stop safely before 5 minutes, save progress in `PropertiesService`, and tell the user to run again. A second run continues where it stopped.
6. Show a final toast: generated count, skipped (incomplete) count.

## Boundary
Do not change `Summary` or `Evaluations`. Read only.
