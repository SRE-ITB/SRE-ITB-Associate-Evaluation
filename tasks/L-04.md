## Goal
PROD runs all automations under the org account, and OM confirms the system works with real data.

## Context
`docs/01-architecture.md` section 5. Triggers installed from a personal account stop when that account loses access.

## Suggested steps
1. `Triggers.gs`: `installTriggers()` removes existing project triggers, then installs the four in the table. Idempotent.
2. Deploy main to PROD (`docs/03-workflow.md` section 6).
3. Logged in as the org account, run `installTriggers()` once from the editor. Accept the authorization prompt.
4. Run `syncForm()` and `openPeriod('P1')`.
5. UAT with OM (27-28 Nov):
   - Each tester submits one evaluation, checks it in `Evaluations`, edits a value, checks `Summary`.
   - Walk through Red Notice, Best Staff, tie override, and an OM-staff case with the `Asso OM` role.
   - Trigger a birthday run with a test row dated today, then delete the test data.
   - Generate report cards and Best Staff posters for a fully filled test period.
   - Submit from an email not in `Admins` and confirm it lands in `Rejected`.
6. Record UAT findings as issues. Fix before 30 Nov.
7. Start `docs/05-operations.md`: list of triggers, owner account, how to open a new period. Full runbook comes with the guidebook.

## Boundary
Delete all UAT test rows and test outputs before 30 Nov.
