## Goal
`Summary` shows the correct final scores and status for every staff, live, as `Evaluations` changes.

## Context
- Rules: `docs/00-scope.md` sections 7 and 8, in that exact status order.
- Column layout and sketches: `docs/01-architecture.md` section 2.5.
- Exclude `IGNORED_OM_ROLE` rows everywhere.

## Suggested steps
1. Build the template row formulas for columns E-Q.
2. `final_total`: round to 4 decimals before comparing, to avoid floating point ties like 15.2 vs 15.200000001.
3. `status_auto`: Incomplete, then Red Notice, then Best Staff / Tie among complete non-Red-Notice staff of the same division and period, then Normal. Best Staff shows as `Best Staff (Sementara)` while `division_complete` is FALSE (D-024).
4. `status`: apply `tie_override`. If one tied staff is ticked, that staff is `Best Staff`, the other tied staff are `Normal`. If more than one is ticked, show `Tie` for all of them.
5. `division_complete`: TRUE when every staff of the division in that period is complete.
6. Copy the final formulas into `docs/01-architecture.md` section 2.5.

## Boundary
No script for scoring. Formulas only, so values update live after manual edits.
