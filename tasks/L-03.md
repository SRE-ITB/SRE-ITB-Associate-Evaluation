## Goal

## Context
Column order and Form titles are a contract that A-01 and B-01 code against. Lock them before devs start.

## Suggested steps
1. Create every tab with headers from `docs/01-architecture.md` section 2.
2. Fill `Config`: keys, periods table with P1 = 2026-12-01 to 2027-02-28, OM emails, folder IDs.
3. Import OM's staff data into `Master`. Map divisions to the exact values in `docs/00-scope.md` section 3, including the E&C Research/Product split. Exclude Kadiv/Wakadiv and GenSec units.
4. Check every `photo_file_id` opens from the org account. If photos are owned by others and not shared, ask OM to share them or copy them into a folder owned by the org account.
5. Fill `Admins` with every Kadiv/Wakadiv of the 13 groups and every asso OM.
6. Create the Form in `System/` with section 1 and 13 division sections (fields from section 3 of the architecture doc). Staff dropdowns can stay empty; B-01 fills them. Link it to the spreadsheet and rename the response tab to `Form Responses`.
7. Set protected ranges and data validation per section 2.
8. Share the spreadsheet with all admins as Editor. Share the Form link with admins only.
