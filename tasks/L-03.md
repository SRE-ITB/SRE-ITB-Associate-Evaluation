## Goal
PROD spreadsheet and Form exist with the exact structure in `docs/01-architecture.md`, and `Master` holds real, verified data for every SRE member.

## Context
Column order and Form titles are a contract that A-01 and B-01 code against. Lock them before devs start.

## Suggested steps
1. Set `ENV = PROD` and `LEAD_EMAIL` in `Config`, then run `setupSheets()` from the editor as the org account. It creates every tab with headers from `docs/01-architecture.md` section 2. Never run `seedFakeData()` in PROD.
2. Fill `Config`: keys, periods table with P1 = 2026-12-01 to 2027-02-28, OM emails, folder IDs.
3. Import every SRE member into `Master` (D-032). Staff of the 13 evaluation groups get `evaluated = TRUE` and a division value from `docs/00-scope.md` section 3, including the E&C Research/Product split. Kadiv/Wakadiv, General Secretariat units, and other members get `evaluated = FALSE`; their division is free text for the birthday poster.
4. Check every `photo_file_id` opens from the org account. If photos are owned by others and not shared, ask OM to share them or copy them into a folder owned by the org account.
5. Fill `Admins` with every Kadiv/Wakadiv of the 13 groups and every asso OM.
6. Run `setupForm()`. It creates the Form with section 1 and 13 division sections (fields from section 3 of the architecture doc), links it to the spreadsheet, renames the response tab to `Form Responses`, and writes `FORM_ID` to `Config`. Move the Form file into `System/`. Staff dropdowns hold `(no staff)` until B-01 fills them.
7. Run `setupProtections()` for protected ranges per section 2. Data validation is set by `setupSheets()`.
8. Share the spreadsheet with all admins as Editor. Share the Form link with admins only.

## Boundary
Do not export `Master` outside Drive. Do not paste it in chat or the repo.
