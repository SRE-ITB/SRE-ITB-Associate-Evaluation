## Goal
OM generates one Best Staff poster per division for a period, from the menu, once results are final.

## Context
- Rules: `docs/00-scope.md` section 12.
- Template placeholders: `{{name}}`, `{{division}}`, `{{period}}`, image `{{photo}}`.
- Reuse `renderPoster` from `Posters.gs`.

## Suggested steps
1. `generateBestStaffPosters(periodId)`: per division, read `Summary` for that period.
2. Generate only when `division_complete` is TRUE and exactly one staff has `status = Best Staff` (not `Best Staff (Sementara)`).
3. Otherwise skip the division and report why: incomplete, unresolved tie, or no eligible staff.
4. Save to `BestStaff/<period>/<division>.png`, overwriting a previous run.
5. Show a summary dialog: generated divisions and skipped divisions with reasons.

## Boundary
Read only on sheets.

## Done =
- [ ] Complete division with one Best Staff: one poster with correct name, photo, period.
- [ ] Division with an unresolved tie is skipped with reason `tie`.
- [ ] Incomplete division is skipped with reason `incomplete`.
- [ ] Running twice does not create duplicates.
