## Goal
Devs can clone the repo and `clasp push` to their own DEV copy on day one.

## Context
`docs/03-workflow.md` sections 1-2. The repo should live in the SRE ITB GitHub organization, not a personal account, so it survives handover.

## Suggested steps
1. Create the repo in the SRE ITB GitHub org, public (D-029). Add Dev A, Dev B, Dev C. Protect `main`: PR required, 1 approval, code owner review, required CI checks, no force push.
2. From the org account, create the PROD spreadsheet (empty) in `System/`. Open Extensions > Apps Script to create its bound script. `clasp clone` it, set `rootDir: src`. L-03 builds the tabs.
3. `appsscript.json`: `"timeZone": "Asia/Jakarta"`, `"runtimeVersion": "V8"`.
4. `Config.gs`: sheet name constants, column indexes, Form field titles from `docs/01-architecture.md`, `getConfig()` reading the `Config` tab.
5. Create DEV copies in `DEV/`, one per dev: a new spreadsheet, `clasp push`, set `ENV = DEV` in `Config`, then run `setupSheets()`, `seedFakeData()`, and `setupForm()`. Verify each copy has its own linked Form and its own script ID.
6. Commit `.clasp.example.json` and `.gitignore` (`.clasp.json`, `.clasp.prod.json`, `*.csv`, `data/`).
7. Add the PR template, `CODEOWNERS`, CI workflow, and `scripts/deploy-prod.sh` (D-029).

## Boundary
No real staff data in DEV copies or in the repo.
