## Goal
The Form always lists the current periods and, per division section, only the active staff of that division.

## Context
- Form structure and titles: `docs/01-architecture.md` section 3.
- Division values: `docs/00-scope.md` section 3.
- Dropdown item format: `Name (NIM)`.

## Suggested steps
1. Open the Form by `FORM_ID` from `Config`.
2. Set the `Period` dropdown choices from `PERIODS`.
3. For each `Staff - <division>` item, set choices to active `Master` staff of that division, sorted by name.
4. If a division has no active staff, set a single choice `(no staff)` and log a warning.
5. Do not recreate items: update choices on the existing items so the response columns stay stable.
6. Add `Sync Form` to the menu. The daily trigger is installed in L-04.

## Boundary
Do not add, remove, or rename Form items or sections. That changes the response sheet columns.

## Done =

- [ ] Setting a staff to `active = FALSE` removes them after sync.
- [ ] Two staff with the same name are distinguishable by NIM.
- [ ] Running sync does not change the column layout of `Form Responses`.
