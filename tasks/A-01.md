## Goal
Every Form submission becomes exactly one up-to-date row in `Evaluations`, and manual edits are stamped.

## Context
- Rules: `docs/00-scope.md` sections 6 and 9.
- Columns and Form titles: `docs/01-architecture.md` sections 2.4 and 3. Use the constants in `Config.gs`.
- Role mapping: `Kadiv/Wakadiv representative` -> `KW`, `Asso OM` -> `OM`.

## Suggested steps
1. `onFormSubmitHandler(e)`: read `e.namedValues`. Find the one non-empty `Staff - <division>` field, parse NIM from `Name (NIM)`.
2. Look up the staff in `Master` (name, division). If not found or inactive, log and stop.
3. If the submitter email is not in `Admins`: append to `Rejected` with reason `NOT_REGISTERED`, email the submitter that the submission was not recorded and they must use their registered account, then stop.
4. Compute `flag`:
   - `IGNORED_OM_ROLE` if division is `Organizational Management` and role is `OM`.
   - `ROLE_MISMATCH` if the email is in `Admins` but with another role (or, for `KW`, another division).
5. Under a script lock, find the row by `(period_id, nim, role)`. Update it if found, otherwise append. Set `submitted_by` (verified email), `updated_at`, `source = FORM`.
6. `onEditHandler(e)`: exit unless the edit is in `Evaluations!F:J`. Stamp `updated_at`, `source = MANUAL`, `submitted_by` = active user email or `MANUAL (unknown)`. Handle multi-cell edits (paste).
7. `openPeriod(periodId)`: append one `Summary` row per active staff for that period if not already present, copying formulas from the template row. Add a menu entry.

## Boundary
Do not change `Summary` formulas (A-02) or the Form structure (B-01, L-03).

## Done =
- [ ] Submitting twice for the same period, staff, and role leaves one row with the latest values.
- [ ] KW and OM submissions for the same staff produce two rows.
- [ ] An `Asso OM` submission for an OM staff is stored with `IGNORED_OM_ROLE`.
- [ ] A submitter not in `Admins` writes nothing to `Evaluations`, appears in `Rejected`, and receives the notice email.
- [ ] A listed KW admin evaluating another division is written with `ROLE_MISMATCH`.
- [ ] Editing `i3` by hand updates `updated_at` and `source = MANUAL`. Pasting over 3 rows stamps all 3.
- [ ] `openPeriod('P1')` twice creates rows only once.

## How to demo
In a DEV copy: submit the Form as KW and OM for fake staff A and B from `docs/00-scope.md` section 8, then edit one value.
